# تحديث تطبيق مكتب المحامي فريد حسام عبدالهادي

## محتويات النسخة
- `main.dart`: واجهات التطبيق المعدلة مع الإبقاء على ربط Supabase والمنطق الحالي لإدارة العملاء والقضايا والجلسات.
- `pubspec.yaml`: إضافة تعريف أصل الشعار.
- `assets/images/fareed_logo.png`: الشعار المرسل.

## التثبيت داخل مشروع Flutter
استبدل `lib/main.dart` بهذا الملف، واستبدل `pubspec.yaml`، ثم انسخ مجلد `assets` إلى جذر المشروع.
بعدها نفّذ:

```bash
flutter pub get
flutter run
```

## ملاحظات
- الخدمات المعروضة: القضايا التجارية، القضايا الجنائية، القضايا المدنية، والأحوال الشخصية.
- أزرار الخدمات تفتح قسم القضايا الحالي؛ لم تتم إضافة وحدات مستقلة لأنواع القضايا.
- أزرار إضافة قضية وحجز جلسة في لوحة المكتب تستخدم النماذج الحالية.
- بيانات الاتصال المعروضة مأخوذة من التصميم المرجعي المرسل، يرجى مراجعتها قبل النشر.
- لم يتم تغيير إعدادات Supabase أو مخطط قاعدة البيانات.
